# Portfolio Pessoal

Site pessoal responsivo com meus dados, experiência profissional, habilidades e projetos — disponível em **Português e Inglês**.

🔗 **Acesse:** [kaueloviz.github.io/Portfolio-Pessoal](https://kaueloviz.github.io/Portfolio-Pessoal/)

## Funcionalidades ✨

- 🌐 Alternância de idioma (PT-BR / EN) direto no menu
- 🌗 Tema claro / escuro com preferência salva
- 📱 Totalmente responsivo (mobile, tablet e desktop)
- 📄 Download do currículo em PDF
- 🖼️ Carrossel de portfólio e depoimentos
- ✉️ Contato direto por e-mail

## Tech Stack 📝

**Front-end:** HTML5, CSS3 e JavaScript.
**Bibliotecas:** [Swiper](https://swiperjs.com/) (carrosséis) e [AOS](https://michalsnik.github.io/aos/) (animações on scroll).

## Rodando localmente 🚀

Por ser um site estático, basta abrir o `index.html` no navegador ou servir a pasta com qualquer servidor HTTP simples, por exemplo:

```bash
npx serve .
```
